## 2. Design-richting

**"Graphite + Signal Cyan"** — rustige graphite-oppervlakken, één signaalkleur voor interactie en status.

- **Accent:** `#38bdf8` (tekst/iconen), primaire knop `#0369a1` (wit erop ≥ 5.9:1), hover `#0284c7`.
- **Accent-gebruik:** alleen voor actieve navigatie, focus, primaire actie, geselecteerde rand. Niet decoratief.
- **Semantiek:** success `#34d399`, warning `#fbbf24`, danger `#f87171` — ongewijzigd.
- **Data:** categorisch palet cyaan → violet → groen → amber → roze → grijs.
- **Hiërarchie per dashboard:** Paginatitel → KPI's → activiteit → context/branding.

## 3. Doorgevoerde restyle

- `ui/src/styles/tokens.css` — dark-theme accent, focus, nav-active, selected-border, primaire knop, grafiekpalet, iets sterkere borders/muted tekst.
- `ui/src/components/layout/AppShell.css` — shell-grid 3 rijen.
- `ui/src/components/layout/TopBar.css` — mobiele top bar op één rij.
- `ui/src/pages/Overview/OverviewPage.tsx|.css` — KPI's eerst, hero responsive zonder overflow, 2-up KPI's mobiel.
- `ui/src/app/ErrorBoundary.tsx` — crashfix.

## 4. Aanbevolen vervolg (prioriteit)

1. Sidebar herstructureren: 5–7 groepen, inklapbaar, pinbare favorieten.
2. Workspace-toolbar samenvoegen tot één "View"-menu in de top bar.
3. Statusredundantie op Overview opruimen (één verbindingsindicator in de top bar).
4. Monospace beperken tot code/ID's; eyebrows in sentence case.
5. UX-copy van lege/foutstaten herschrijven richting actie ("Vraag je beheerder om…").
