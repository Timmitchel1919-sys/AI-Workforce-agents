# Layer 3 objective (Layer 33)

Layer 3 extends the existing Spatial Graph projection and renderer into a premium operational surface. It does not create a second graph engine or duplicate authoritative state.

The first integration is read-only: an operational summary is computed from the exact authorized projection already shown on screen. Projects, agents, tasks, dependencies, executions and operational state remain grounded in Control Plane graph nodes and edges. Missing data remains unavailable; the UI does not infer hidden resources.

Future spatial operations must preserve the same rules: server-side scope, bounded projections, redacted metadata, explicit confirmation for commands, accessible list parity, reduced-motion support and non-mutating navigation/filtering by default.
